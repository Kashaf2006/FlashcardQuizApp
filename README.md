
# 📚 Flashcard Quiz App

A simple and interactive flashcard app built for studying and quick revision. This project was completed as **Task 1** of my App Development Internship at **CodeAlpha**.

## ✨ Features
- Each flashcard has a question on the front and an answer on the back, revealed with a "Show Answer" button
- Navigate between cards using **Next** and **Previous** buttons
- **Add, edit, and delete** flashcards for full customization
- Clean and simple user interface for easy use

## 🛠️ Built With
- HTML
- CSS
- JavaScript (vanilla, no frameworks)

## 🚀 How to Run
1. Download or clone this repository
2. Open `index.html` in any web browser
3. Start studying! Add your own flashcards using the form at the bottom
